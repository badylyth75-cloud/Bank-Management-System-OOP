# Bank Management System — OOP

**A Console-Based Banking Application Built with C++ and Object-Oriented Programming**

This project is an educational implementation of a Bank Management System developed using C++. It focuses on applying Object-Oriented Programming (OOP) principles, organizing code into reusable classes, and separating application responsibilities.

## Features

- **Client Management:** Manage bank client information.
- **User Management:** Organize user-related functionality separately from client functionality.
- **Access Permissions:** Use a permissions system to control access to application features.
- **File-Based Storage:** Store and retrieve application data using text files.
- **Reusable Components:** Share common functionality through reusable classes and methods.
- **Organized Console Interface:** Separate screen-related functionality from application logic.

## Technologies Used

- **Language:** C++
- **Programming Paradigm:** Object-Oriented Programming (OOP)
- **IDE:** Microsoft Visual Studio
- **Data Storage:** Text files

## OOP Concepts Applied

- **Encapsulation:** Control access to class data and functionality.
- **Inheritance:** Reuse common functionality through base and derived classes.
- **Abstraction:** Hide implementation details behind class interfaces.
- **Separation of Responsibilities:** Organize classes according to their roles.

## Project Structure

The project contains the following main components:

- `Coar/` — Core classes and related functionality.
- `LPy/` — Additional project classes.
- `Screen/` — Console screen and user-interface functionality.
- `main.cpp` — Application entry point.
- `Global.h` — Shared declarations and global definitions.

## Getting Started

### Prerequisites

- Windows
- Microsoft Visual Studio with the **Desktop development with C++** workload installed.

### Installation and Execution

1. Clone or download this repository.
2. Open `ClsLibary.slnx` in Visual Studio.
3. Build the solution.
4. Run the application.

**Note:** The application uses text files for data storage. Keep the required data files in the locations expected by the source code.

This project is part of my journey in learning C++ and applying Object-Oriented Programming principles to a practical software application.

It helped me practice class design, encapsulation, inheritance, code reuse, and separation of responsibilities.

# نظام إدارة البنك — البرمجة كائنية التوجه

**تطبيق بنكي يعمل عبر سطر الأوامر باستخدام C++ ومفاهيم البرمجة كائنية التوجه**

هذا المشروع تطبيق تعليمي لنظام إدارة بنك، تم تطويره باستخدام لغة C++، بهدف تطبيق مفاهيم البرمجة كائنية التوجه (Object-Oriented Programming — OOP)، وتنظيم الكود في كلاسات قابلة لإعادة الاستخدام، وفصل المسؤوليات بين أجزاء التطبيق.

## المميزات

- **إدارة العملاء:** تنظيم وإدارة معلومات عملاء البنك.
- **إدارة المستخدمين:** فصل الوظائف المتعلقة بالمستخدمين عن الوظائف المتعلقة بالعملاء.
- **نظام الصلاحيات:** استخدام نظام للصلاحيات للتحكم في الوصول إلى وظائف التطبيق.
- **التخزين باستخدام الملفات:** حفظ بيانات التطبيق واسترجاعها باستخدام الملفات النصية.
- **إعادة استخدام الكود:** مشاركة الوظائف المشتركة من خلال الكلاسات والدوال القابلة لإعادة الاستخدام.
- **تنظيم واجهة الاستخدام:** فصل وظائف الشاشات عن منطق التطبيق.

## التقنيات المستخدمة

- **لغة البرمجة:** C++
- **النمط البرمجي:** البرمجة كائنية التوجه (OOP)
- **بيئة التطوير:** Microsoft Visual Studio
- **تخزين البيانات:** الملفات النصية (Text Files)

## مفاهيم OOP المطبقة

- **التغليف (Encapsulation):** تنظيم الوصول إلى بيانات الكلاسات ووظائفها.
- **الوراثة (Inheritance):** إعادة استخدام الوظائف المشتركة من خلال الكلاسات الأساسية والمشتقة.
- **التجريد (Abstraction):** إخفاء تفاصيل التنفيذ خلف واجهات الكلاسات.
- **فصل المسؤوليات (Separation of Responsibilities):** تنظيم الكلاسات بحسب وظيفة كل منها.

## هيكل المشروع

يحتوي المشروع على المكونات الرئيسية التالية:

- `Coar/` — الكلاسات الأساسية والوظائف المرتبطة بها.
- `LPy/` — كلاسات إضافية في المشروع.
- `Screen/` — وظائف الشاشات وواجهة الاستخدام النصية.
